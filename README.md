# A Comparative Study of Extractive and Abstractive Text Summarization Techniques

Data mining project comparing nine automatic text summarization methods — spanning statistical/graph-based extractive, clustering-based extractive, supervised sentence-selection, and transformer-based abstractive approaches — on the BBC News Summary dataset.

**Authors:** Anish Kumar Singh, Jeewan Bhatt
Department of Electronics and Computer Engineering, Thapathali Campus, Institute of Engineering, Tribhuvan University, Kathmandu, Nepal

## Overview

Automatic text summarization reduces the effort needed to consume long documents. This project implements and empirically compares nine summarization techniques on 2,225 BBC news articles across five categories (business, entertainment, politics, sport, technology), each paired with a human-written reference summary. Methods are evaluated on both **summary quality** (ROUGE-1, ROUGE-2, ROUGE-L F1) and **computational cost** (average runtime per article).

## Methods Implemented

| Category | Method | Principle |
|---|---|---|
| Statistical / graph-based extractive | TF-IDF Centroid | Sentences ranked by cosine similarity to the document centroid |
| | TextRank | Graph-based ranking (PageRank) over a sentence similarity graph |
| Clustering-based extractive | K-Means | Sentences grouped into k clusters; centroid-closest sentence per cluster selected |
| | Agglomerative Hierarchical (Ward linkage) | Bottom-up merging of sentence clusters |
| | DBSCAN | Density-based clustering; no predefined cluster count, handles noise |
| Supervised sentence selection | Gaussian Naive Bayes | Probabilistic classifier on engineered sentence features |
| | Decision Tree | Rule-based classifier, with pruning to control overfitting |
| | K-Nearest Neighbors (k=5) | Distance-based classification on scaled features |
| Abstractive (transformer) | BART (`facebook/bart-large-cnn`) | Pretrained sequence-to-sequence model that generates novel summary text |

Sentence-level features engineered for the supervised and centroid-based methods: `position`, `length`, `centroid_sim` (TF-IDF cosine similarity to document centroid), and `title_sim` (similarity to the article headline).

## Pipeline

1. **Data acquisition** — BBC News Summary dataset downloaded via `kagglehub` (`pariza/bbc-news-summary`).
2. **Preprocessing** — headline/body separation, sentence tokenization (NLTK Punkt), Latin-1→UTF-8 encoding correction, stopword removal, lemmatization.
3. **Feature extraction** — TF-IDF vectorization and cosine similarity.
4. **Weak supervision** — sentence-level relevance labels generated by matching article sentences to reference-summary sentences via TF-IDF similarity threshold, used to train the supervised classifiers.
5. **Summarization** — all nine methods applied to each article.
6. **Evaluation** — ROUGE-1/2/L F1 against reference summaries; runtime benchmarking; diagnostic analysis of reference-summary extractiveness and BART performance vs. summary length.

## Results

### ROUGE F1 Performance

| Method | ROUGE-1 | ROUGE-2 | ROUGE-L |
|---|---|---|---|
| **TextRank** | **0.4128** | **0.3955** | **0.3517** |
| TF-IDF Centroid | 0.4099 | 0.3925 | 0.3498 |
| DBSCAN | 0.4038 | 0.3844 | 0.3444 |
| Hierarchical | 0.3666 | 0.3305 | 0.3171 |
| K-Means | 0.3607 | 0.3213 | 0.3121 |
| BART (abstractive) | 0.2950 | 0.1961 | 0.2249 |

### Average Runtime per Article

| Method | Time / Article |
|---|---|
| TF-IDF Centroid | 0.43 ms |
| Hierarchical | 1.31 ms |
| TextRank | 2.44 ms |
| DBSCAN | 8.69 ms |
| K-Means | 74.53 ms |
| BART | 611.11 ms |

**Key findings:**
- TextRank achieved the strongest ROUGE performance overall, closely followed by TF-IDF and DBSCAN.
- Extractive methods are 250–1400× faster than BART per article.
- The BBC reference summaries are highly extractive in composition, giving extraction-based methods a structural advantage under lexical-overlap (ROUGE) evaluation — a lower ROUGE score for BART does not necessarily mean lower human-perceived quality.

## Usage

1. Clone the repository and open `data_mining_project_report.ipynb` in Jupyter.
2. Run the cells sequentially — the first cell downloads the BBC News Summary dataset via `kagglehub` automatically.
3. NLTK resources (`punkt`, `punkt_tab`, `stopwords`, `wordnet`, `omw-1.4`) are downloaded within the notebook on first run.
4. A GPU is recommended for the BART inference cells but is not required.

## Dataset

[BBC News Summary](https://www.kaggle.com/datasets/pariza/bbc-news-summary) (Kaggle) — 2,225 news articles across 5 categories, each with a human-written reference summary.
